# 建设者之家 · 账务系统

工地旁便民超市的记账工具：开单收银、赊账台账、进货应付、库存结余、统计看板，一个页面管住。

## 在线使用

打开 https://lubiaorenwu.github.io/jianzhezhijia/ 即可用。

**数据存在你自己的浏览器里**（localStorage），不上传、不联网、不经过任何服务器。
换设备或换浏览器就是一本新的账，所以：

- 想多台设备共用一本账 → 用电脑上的本地局域网版（`账务服务.py`，手机连同一个 WiFi）
- 换手机/清浏览器缓存前 → 先在「数据与设置」里下载备份 JSON

## 登录

首次打开会引导你创建管理员账号和密码（密码加盐哈希后存在本机，不上传）。
之后在「数据与设置 → 用户与权限」里可以加店员账号（店员只能开单记账）。
这是**界面级**权限：能分账追责、防误操作，不能防懂技术的人改前端。

## 本地局域网版（手机电脑共用一本账）

需要电脑上装了 Python，双击 `启动账务服务.cmd`，手机连同一个 WiFi 打开黑窗口里的地址。
数据落在电脑上的 `data.json`，同样不上传。
